# Android-Projekt-Beadando
Zenekereső/lejátszó app

Egy Jamendo API-t használó zenelejátszó app.
Megvalósítandó funkciók 
    • Zenelejátszó
    • Zenék megjelenítése listában 
    • Listából kiválasztott Zene részletes nézete 
        o Zenéhez tartozó poster megjelenítése 
        o Hozzáadás a kedvencekhez 
    • Keresés Zene címe alapján, keresési eredmények megjelenítése listában 
    • Kedvenc zenék megjelenítése listában 
        o Offline adattárolás lokális adatbázisban
    • A hkét lista (zenék, kedvencek) között Tab Bar/Bottom Navigation segítségével 
      navigálhatunk 
    • Listás megjelenítés RecyclerView vezérlőelemmel valósul meg 
    • Lokális adatbázis Architecture Components Room segítségével valósul meg
